# DearTech-OS Starter Kit: ChatGPT bundle

This file combines the note template and the starter notes into one upload.
Upload this file to a ChatGPT Project. Paste AGENTS.md into the Project instructions.
Do not upload AGENTS.md as well.
The Free plan allows 5 files per Project. This one file fits that limit.

Generated by `npm run bundle`. Do not edit this file by hand.
After you change a note, run `npm run bundle` again from the kit folder.
